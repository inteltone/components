# Components

Коллекция переиспользуемых UI-компонентов для веб-проектов.

## Содержание

- `before-after-slider/` — слайдер для сравнения изображений "до/после"
- *другие компоненты будут добавляться по мере необходимости*

## Назначение

Этот репозиторий — моя персональная библиотека готовых решений, которые часто используются на сайтах: слайдеры, аккордеоны, модальные окна, табы и другие интерфейсные элементы.

Каждый компонент максимально автономен и может быть скопирован в любой проект.
